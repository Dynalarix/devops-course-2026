# Мой пет-проект
Идея: Telegram-бот для запоминания английских слов по методу интервальных
повторений — бот присылает карточки со словами, а слова, в которых я ошибаюсь,
показывает чаще.
Стек: Python (aiogram), SQLite
Цель: научиться упаковывать бота в Docker и автоматически деплоить его
на сервер через GitHub Actions.
