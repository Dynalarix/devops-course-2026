# Цели на семестр

1. Уверенно работать с Git в терминале: ветки, rebase, разрешение конфликтов,
   работа с несколькими remote — без подсказок и шпаргалок.
2. Упаковать собственный pet-проект в Docker-образ и описать запуск через docker compose.
3. Настроить CI/CD-пайплайн в GitHub Actions: линтер, тесты и автоматический деплой
   учебного проекта на сервер.
