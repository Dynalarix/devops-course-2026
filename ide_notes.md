# Git в IDE vs в терминале

Использую VSCodium — open-source сборку VS Code без телеметрии Microsoft
(расширения ставятся из Open VSX, GitLens там тоже есть).

## Что удобно делать в VSCodium
1. Смотреть diff: изменения подсвечиваются прямо в редакторе, а в Source Control
   видно «было/стало» в двух колонках.
2. Частичный stage: можно добавить в индекс только выбранные строки файла
   (Stage Selected Ranges) — в терминале для этого нужен `git add -p`.
3. GitLens (git blame в строке): сразу видно, кто, когда и в каком коммите
   последний раз менял строку, плюс удобная визуальная история веток.

## Что удобнее делать в терминале
- Interactive rebase, cherry-pick, reflog и работа с несколькими remote:
  в терминале всё явно и предсказуемо, команды можно записать в скрипт,
  а на сервере по SSH никакой IDE всё равно не будет.
